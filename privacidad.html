Política de privacidad

Trader Lab · vigente desde el 8 de noviembre de 2026

Quién la usa

Trader Lab es una herramienta de uso personal. La única persona autorizada a usarla es su propietario, Paul Etienne. No está abierta al público ni recolecta datos de otras personas.

A qué accede en la cuenta de Google

  • Google Sheets: lee y escribe la hoja de cálculo "Trader Lab · Alpaca Paper", que funciona como base de datos del sistema.
  • Google Drive: busca y lee archivos del propietario cuyo nombre empieza con "TraderLab_release_" (versiones del código) y crea archivos "TraderLab_respaldo_" (copias de seguridad). No lee otros archivos.
  • Google Apps Script: actualiza el código de su propio proyecto y publica nuevas versiones, solo cuando el propietario lo confirma.
  • Correo: envía resúmenes y alertas únicamente a la dirección del propietario.
  • Correo de la cuenta: lo usa para verificar que quien abre el tablero es el propietario.

Qué datos salen de Google

Para funcionar, el sistema consulta servicios externos y envía solo lo necesario: órdenes y consultas de mercado a Alpaca (cuenta de práctica), consultas de precios públicos a Coinbase y, si el propietario lo activa, datos de mercado a la API de Anthropic para el análisis. No se envían datos personales ni contenido de Google Drive o Gmail a terceros.

Almacenamiento y seguridad

Los datos quedan en la hoja de cálculo y en el Drive del propietario. Las claves de acceso a servicios externos se guardan en las propiedades de un proyecto de Apps Script separado y nunca se publican ni se comparten.

Venta o uso para publicidad

Trader Lab no vende, comparte ni usa datos para publicidad. El uso de información recibida de las API de Google cumple la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/connections.
